# Отчет по лабораторной работе №1: Первые программы на Python

## Инструкция по запуску
Для запуска программ необходим установленный интерпретатор Python 3.13 или 3.14.
1. Откройте терминал (командную строку).
2. Перейдите в папку с файлами лабораторной работы (например, `cd путь/к/папке`).
3. Запустите нужный файл командой `python <имя_файла>.py` (или `py <имя_файла>.py` для Windows).

В ходе лабораторной работы были написаны следующие программы:

## Теоретические вопросы и объяснение ошибок (`debug.py`)

* **Различие строки и числа (Фрагменты А и Б):** Строка (`str`) — это текст. При сложении строк (`"2" + "3"`) они склеиваются в `"23"`. Числа (`int`, `float`) используются для математики (`2 + 3 = 5`). Так как `input()` всегда возвращает строку, для расчетов ее нужно преобразовывать через `int()`. Это было исправлено во фрагментах А и Б.
* **Порядок вычислений (Фрагмент В):** В Python действуют классические правила математики (сначала умножение/деление, потом сложение/вычитание). Чтобы изменить порядок и сначала найти сумму для среднего арифметического, нужно использовать круглые скобки: `(first + second + third) / 3`.
* **Назначение временной переменной:** При обмене значений двух переменных (`a` и `b`), если просто написать `a = b`, исходное значение `a` безвозвратно потеряется. Временная переменная (в моем коде `name`) нужна для того, чтобы "запомнить" старое значение первой переменной.
* **Форматирование денежного вывода:** Для денег принято выводить копейки/центы всегда двумя знаками. Конструкция `:.2f` внутри f-строки принудительно делает ровно два знака после запятой (например, `12.5` $\rightarrow$ `12.50`), что делает вывод аккуратным.

## Проверка работы программ (тестирование)

### 1. Базовый вывод (`hello.py`)
* Ожидаемый результат: Вывод строк `Изучаю Python` и `Лабораторная работа 1`. (Тест пройден)

### 2. Карточка студента (`profile.py`)
* Ввод: Возраст `17`, Часы: `10.5` $\rightarrow$ Вывод: Возраст через 4 года `21`, за 4 недели `42.00`, в день `1.50` (Ожидания совпали — тест пройден)
* Ввод: Возраст `18`, Часы: `0` $\rightarrow$ Вывод: За 4 недели `0.00`, в день `0.00` (Тест пройден)

### 3. Учебная нагрузка (`workload.py`)
* Ввод: П1 (3 по 90), П2 (2 по 45), доступно 10 ч. $\rightarrow$ Вывод: Время 1 `270`м, Время 2 `90`м, Всего `360`м (`6.00`ч), Остаток `4.00`ч, За 4 недели `24.00`ч (Тест пройден)
* Ввод: П1 (0 по 90), П2 (0 по 45), доступно 10 ч. $\rightarrow$ Вывод: Общая нагрузка `0.00`ч, остаток `10.00`ч (Тест пройден)

### 4. Исправление ошибок (`debug.py`)
* Ввод (для Фрагмента Б): Возраст `17`.
* Вывод программы: `5`, `18`, `7.0` (Ожидалось: `5`, `18`, `7.0` — ошибки исправлены, тест пройден)

### 5. Обмен значениями (`swap.py`)
* Исходные данные (в коде): `401` и `332`.
* Вывод программы: `332` и `401` (Ожидалось, что переменные поменяются значениями — тест пройден)

### 6. Индивидуальный вариант 4 (`variant4_2.py`)
**Предварительный ручной расчет (до запуска программы):**
* Заказ: Альбомы (3 шт по 12.50) = 37.50р; Наборы кистей (2 шт по 20.00) = 40.00р. 
* Итого без доставки: 77.50р. Количество позиций: 5.
* Итого с доставкой (10.00): 87.50р.
* Внесено: 100.00р. Сдача: 12.50р.

**Проверки программы:**
* Стандартный тест (как в ручном расчете) $\rightarrow$ Вывод программы: без доставки `77.50р`, с доставкой `87.50р`, сдача `12.50р`, количество `5` (Совпадает с прогнозом — тест пройден).
* Особая проверка 1 (Нулевое кол-во): `0` альбомов, `2` набора по `20` $\rightarrow$ Стоимость первой позиции `0.00р`, второй `40.00р` (Тест пройден).
* Особая проверка 2 (Бесплатная доставка): Доставка `0` $\rightarrow$ Суммы без доставки и с доставкой равны (Тест пройден).
* Особая проверка 3 (Без сдачи): Внесено ровно по чеку $\rightarrow$ Сдача `0.00р` (Тест пройден).
