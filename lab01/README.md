Как запустить программы
Для запуска программ необходим установленный интерпретатор Python 3.13 или 3.14. 

1.	Откройте терминал (командную строку).

2.	Перейдите в папку с файлами лабораторной работы (например, cd путь/к/папке).

3.	Запустите нужный файл командой python <имя_файла>.py или py <имя_файла>.py (для Windows). Например: python variant4.py.

Ответы на теоретические вопросы

Различие строки и числа:
Строка (str) — это текст, набор символов. Если сложить две строки ("2" + "3"), они просто склеятся ("23"). Число (int или float) используется для математических вычислений, поэтому сумма чисел 2 + 3 даст математический результат 5. Значение из input() всегда является строкой, для расчетов его нужно преобразовать.   

Порядок вычислений:
В Python действуют правила математики: сначала выполняется умножение * и деление /, а затем сложение + и вычитание -. Если нужно изменить этот порядок (например, сначала найти общую сумму для среднего арифметического), необходимо использовать круглые скобки ().   

Назначение временной переменной при обмене:
При обмене значений двух переменных a и b, если мы напишем a = b, исходное значение a будет безвозвратно утеряно. Временная переменная (в моем коде name) нужна для того, чтобы "запомнить" старое значение первой переменной, пока в нее записывается новое значение из второй.   

Форматирование денежного вывода:
Для денег принято указывать копейки/центы всегда двумя знаками, даже если результат — целое число. Конструкция :.2f внутри f-строки принудительно выводит число с плавающей точкой с ровно двумя знаками после запятой (например, 12.5 выводится как 12.50), что делает вывод аккуратным и соответствующим финансовым форматам.
