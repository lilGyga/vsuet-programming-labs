# Отчет по лабораторной работе №3: Условия и логические выражения

## Инструкция по запуску

Для запуска программ необходим установленный интерпретатор Python (версии 3.13 или 3.14).
1. Откройте терминал (командную строку).
2. Перейдите в папку с файлами лабораторной работы.
3. Запустите нужный файл командой `python <имя_файла>.py`.

## Выполненные задания

1. `minimum.py` — нахождение минимального из трех введенных чисел.
2. `calculator.py` — простой калькулятор для двух чисел, обрабатывающий деление на ноль.
3. `point.py` — проверка попадания точки с заданными координатами в прямоугольник.
4. `variant.py` — индивидуальный вариант 4: определение категории результата теста в зависимости от баллов.

## Теоретические вопросы для защиты

* **Выбор `and` / `or`:** 
  Оператор `and` (И) используется, когда нужно, чтобы **оба** условия выполнялись одновременно (например, координата $x \ge 0$ И $x \le 5$). 
  Оператор `or` (ИЛИ) нужен, когда достаточно выполнения хотя бы **одного** условия (например, балл меньше $0$ ИЛИ больше $100$ — в обоих случаях это ошибка).

* **Порядок ветвей (`if` / `elif` / `else`):**
  Программа проверяет условия сверху вниз. Как только она находит первое подходящее условие (`True`), она выполняет его блок кода и пропускает все остальные ветви. Поэтому важно ставить проверки в правильной последовательности. Например, в 4 задании мы сначала отсекаем ошибку диапазона, а затем проверяем категории по возрастанию.

* **Поведение при равенстве значений:**
  В программе `minimum.py` используются нестрогие неравенства (`<=`). Если ввести одинаковые числа (например, `5, 5, 5`), условие `a <= b and a <= c` окажется истинным (`5 <= 5 and 5 <= 5`), и программа корректно выведет `5`, не уходя в ошибку.

## Проверка работы программ (тестирование)

### 1. Минимум трех чисел (`minimum.py`)
* Ввод: `2`, `10`, `3` $\rightarrow$ Вывод: `2` (Ожидалось: `2`)
* Ввод: `5`, `5`, `5` $\rightarrow$ Вывод: `5` (Ожидалось: `5`)
* Ввод: `-4`, `0`, `-2` $\rightarrow$ Вывод: `-4` (Ожидалось: `-4`)
* Ввод: `10`, `8`, `1` (минимум на последней позиции) $\rightarrow$ Вывод: `1` (Ожидалось: `1`)

### 2. Калькулятор (`calculator.py`)
* Ввод: `7`, `2`, `/` $\rightarrow$ Вывод: `3.50` (Ожидалось: `3.50`)
* Ввод: `5`, `0`, `/` $\rightarrow$ Вывод: `Деление на ноль запрещено` (Ожидалось: сообщение об ошибке)
* Ввод: `5`, `2`, `?` $\rightarrow$ Вывод: `Неизвестная операция` (Ожидалось: сообщение об ошибке)
* Ввод: `2.5`, `2.5`, `+` $\rightarrow$ Вывод: `5.00` (Ожидалось: `5.00`)

### 3. Принадлежность прямоугольнику (`point.py`)
* Ввод: `2`, `2` $\rightarrow$ Вывод: `Внутри или на границе` (Ожидалось: внутри)
* Ввод: `5`, `3` $\rightarrow$ Вывод: `Внутри или на границе` (Ожидалось: на границе)
* Ввод: `5.1`, `3` $\rightarrow$ Вывод: `Снаружи` (Ожидалось: снаружи)

### 4. Вариант 4: Результат теста (`variant.py`)
* Ввод: `-1` $\rightarrow$ Вывод: `Ошибка диапазона`
* Ввод: `0` $\rightarrow$ Вывод: `Нужна доработка`
* Ввод: `49` $\rightarrow$ Вывод: `Нужна доработка`
* Ввод: `50` $\rightarrow$ Вывод: `Зачёт`
* Ввод: `84` $\rightarrow$ Вывод: `Зачёт`
* Ввод: `85` $\rightarrow$ Вывод: `Отличный результат`
* Ввод: `100` $\rightarrow$ Вывод: `Отличный результат`
* Ввод: `101` $\rightarrow$ Вывод: `Ошибка диапазона`
*(Все фактические результаты совпали с ожидаемыми границами по таблице из методички).*
