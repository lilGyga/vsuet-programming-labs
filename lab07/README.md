# Отчет по лабораторной работе №7: Функции и автоматические проверки

## Инструкция по запуску

Для работы необходим установленный интерпретатор Python (версии 3.13 или 3.14). Все три файла (`functions.py`, `main.py`, `test_functions.py`) должны находиться в одной папке.

1. Откройте терминал (командную строку) и перейдите в папку с файлами лабораторной работы.
2. **Для запуска автоматических проверок (тестов)** выполните команду:
   ```bash
   python test_functions.py
   ```
3. **Для запуска основной интерактивной программы** выполните команду:
   ```bash
   python main.py
   ```

## Описание файлов работы

1. `functions.py` — модуль с чистыми функциями (без использования `input()` и `print()`):
   * `sum_digits(number)` — вычисление суммы цифр модуля целого числа.
   * `average(numbers)` — расчёт среднего арифметического списка чисел (или `None` для пустого списка).
   * `normalize_text(text)` — приведение строки к нижнему регистру и удаление лишних пробелов.
   * `select_numbers(numbers, threshold)` — индивидуальный вариант 4: отбор чисел не меньше заданного порога (`>= threshold`).
2. `main.py` — программа для взаимодействия с пользователем (ввод данных и вывод результатов работы всех функций).
3. `test_functions.py` — набор автоматических проверок с использованием `assert`.

## Теоретические вопросы для защиты

### 1. Разница между возвратом (`return`) и выводом (`print`)
* Оператор `return` завершает работу функции и передаёт вычисленное значение обратно в то место программы, откуда функция была вызвана. Этот результат можно сохранить в переменную, передать в другую функцию или проверить через `assert`.
* Функция `print()` только выводит текстовое представление данных на экран для человека, но не возвращает значение в программу (сама по себе `print()` возвращает `None`).

### 2. Разница между локальной переменной и параметром
* **Параметр** — это переменная, указанная в скобках при объявлении функции (`def`), через которую функция принимает входные данные (аргументы) в момент вызова.
* **Локальная переменная** — это переменная, которая создаётся непосредственно внутри тела функции для промежуточных вычислений (например, накопитель `total` или список `result`). И параметры, и локальные переменные существуют только внутри своей функции и недоступны снаружи.

### 3. Демонстрация теста, обнаруживающего ошибку
В функции `select_numbers` условие отбора варианта 4 (`if num >= threshold:`) было намеренно заменено на строгое неравенство (`if num > threshold:`). При запуске `python test_functions.py` сработала проверка граничного значения:
```python
assert select_numbers([-5, 0, 2, 5], 2) == [2, 5]
```
Интерпретатор остановил выполнение и выдал ошибку `AssertionError`, так как функция вернула `[5]`, пропустив число `2`, равное порогу. После возврата оператора `>=` все тесты снова стали проходить успешно.
