Для запуска программ необходим интерпретатор Python 3.13 или 3.14.

2. Перейдите в папку с файлами лабораторной работы.
3. Запустите нужный файл командой `python <имя_файла>.py`.

## Ответы на теоретические вопросы
* **Сохранение исходного списка во втором задании:** В `transform.py` создаётся отдельный пустой список `transformed = []`, в который через `.append()` добавляются модули чисел. Сам список `numbers` при этом не модифицируется, поэтому при выводе в конце программы в нём остаются исходные отрицательные значения.
* **Отличие `append()` от присваивания по индексу:** Метод `items.append(value)` добавляет новый элемент в конец списка, увеличивая его длину на 1. Присваивание `items[i] = value` заменяет уже существующий элемент на позиции `i` (если элемента с таким индексом ещё нет, возникнет ошибка `IndexError`).
* **Отличие `sorted()` от `sort()`:** Функция `sorted(items)` не меняет исходный список, а создаёт и возвращает новый отсортированный список. Метод `items.sort()` сортирует сам исходный список «на месте» (изменяя его) и возвращает `None`.
