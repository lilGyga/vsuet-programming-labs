## Задание 3: Предсказание результатов

Ниже представлены выражения, мой ручной прогноз их вычисления и реальный результат выполнения в Python:

| Выражение | Мой прогноз | Результат Python | Объяснение (если отличается или есть нюанс) |
| :--- | :--- | :--- | :--- |
| `2 + 3 * 4` | 14 | 14 | Умножение выполняется раньше сложения. |
| `(2 + 3) * 4` | 20 | 20 | Скобки меняют приоритет: сначала сложение, потом умножение. |
| `17 // 5` | 3 | 3 | Целочисленное деление отбрасывает дробную часть. |
| `17 % 5` | 2 | 2 | Остаток от деления 17 на 5 (17 - 15 = 2). |
| `-7 // 2` | -4 | -4 | Целочисленное деление в Python всегда округляет **вниз** (к меньшему числу). Точный результат -3.5 округляется до -4. |

## Проверка работы программ (тестирование)

Программы были проверены на тестовых данных из методички:

### 1. Перевод времени (`time_parts.py`)
* Ввод: `0` $\rightarrow$ Вывод: `0ч.0мин.0с.` (Ожидалось: `0 ч 0 мин 0 с` — тест пройден)
* Ввод: `59` $\rightarrow$ Вывод: `0ч.0мин.59с.` (Ожидалось: `0 ч 0 мин 59 с` — тест пройден)
* Ввод: `60` $\rightarrow$ Вывод: `0ч.1мин.0с.` (Ожидалось: `0 ч 1 мин 0 с` — тест пройден)
* Ввод: `3600` $\rightarrow$ Вывод: `1ч.0мин.0с.` (Ожидалось: `1 ч 0 мин 0 с` — тест пройден)

### 2. Покупка (`purchase.py`)
* Ввод: `45`, `3`, `135` $\rightarrow$ Вывод: Итог `135`р., Сдача `0`р. (тест пройден)
* Ввод: `45`, `0`, `100` $\rightarrow$ Вывод: Итог `0`р., Сдача `100`р. (тест пройден)

### 3. Индивидуальный вариант 4 (`variant4.py`)
* Ввод: `0` (деталей), `10` (вместимость) $\rightarrow$ Полных: `0`, Остаток: `0`, Всего: `0` (тест пройден)
* Ввод: `20` (деталей), `10` (вместимость) $\rightarrow$ Полных: `2`, Остаток: `0`, Всего: `2` (тест пройден)
* Ввод: `21` (деталей), `10` (вместимость) $\rightarrow$ Полных: `2`, Остаток: `1`, Всего: `3` (тест пройден)
