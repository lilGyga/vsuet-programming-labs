# Лабораторная работа 5. Обработка строк

## Как запустить программы
Для запуска программ необходим интерпретатор Python 3.13 или 3.14. 
1. Откройте терминал.
2. Перейдите в папку с файлами лабораторной работы.
3. Запустите нужный файл командой `python <имя_файла>.py`.

## Ответы на теоретические вопросы
* **Неизменяемость строк:** Строки в Python нельзя изменить частично (например, заменить один символ по индексу). Любой метод вроде `lower()` или `replace()` не меняет оригинальную строку, а создает и возвращает совершенно новую.
* **Отличие слова от подстроки:** Подстрока — это любой кусок текста (даже часть внутри другого слова). Слово — это последовательность символов, отделенная пробелами (то, что получается после `split()`).
* **Почему правила обработки пунктуации задаются заранее:** Символы препинания могут прилипать к словам (например, `слово,`). Если не задать правила очистки (например, не использовать `strip()`), программа посчитает запятую частью слова, и проверки на точное совпадение могут сработать неверно.
